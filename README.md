Descripción

Este proyecto permite medir la temperatura utilizando un Arduino Uno y un sensor de temperatura TMP36 o TMP37. La temperatura detectada se representa mediante tres LEDs rojos que indican diferentes niveles de temperatura.

Componentes
Arduino Uno R3
Sensor de temperatura TMP36 o TMP37
Protoboard
3 LEDs rojos
3 resistencias de 220 Ω
Cables jumper
Funcionamiento

El sensor de temperatura mide la temperatura del ambiente y envía la información al Arduino Uno. Dependiendo de la temperatura detectada, se encienden los LEDs rojos correspondientes al nivel de temperatura establecido en el programa.
